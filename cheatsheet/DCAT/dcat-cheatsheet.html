01总览 · 给数据集发身份证 PART 1 · OVERVIEW

DCAT(Data Catalog Vocabulary)是数据目录词表:把「数据集、发布形态、数据服务、目录」写成 RDF,让目录之间能联合检索。DCAT 3(W3C Rec 2024-08-22)现行,命名空间 dcat: = http://www.w3.org/ns/dcat#。

主线:DCAT 只造骨架词,元数据字段几乎全靠复用——title/publisher/license 取自 dcterms,联系人与主页取自 foaf。

02核心类 · 四级嵌套与两个扩展点 PART 2 · CORE CLASSES
类一句话
dcat:Catalogcurated 的资源集合;自己是 Dataset 的子类——目录也能被收录
dcat:Dataset单一 Agent 发布 / 维护的数据集合(概念实体,经 Distribution 落地)
dcat:Distribution数据集的一种可获取形态:可下载文件、API 端点、落地页
dcat:DataService可访问数据集 / 数据处理功能的 API 服务(DCAT 2 引入)
dcat:ResourceDataset / DataService / Catalog 的公共父类——扩展点,不直接实例化
dcat:Relationship带角色的限定关系(dcterms:relation + dcat:hadRole),经 qualifiedRelation 挂接
dcat:DatasetSeries数据集系列(DCAT 3 新增);CatalogRecord 是收录登记的元数据
嵌套读法 目录列数据集(dcat:dataset)、数据集连发布形态(dcat:distribution)——三层各司其职:目录管收录,数据集管「是什么」,发布形态管「怎么拿」。
03关键属性 · 复用优先的实践 PART 2 · KEY PROPERTIES
属性说明
dcat:distribution / dcat:dataset / dcat:service三条骨架关系:dataset ⊑ dcterms:hasPart——层级直接进 dcterms 体系
dcat:downloadURL / accessURL直接下载地址 vs 访问入口(端点、落地页)——二选一或并存
dcat:mediaType发布形态的 IANA 媒体类型(text/csv 等)
dcat:theme主题分类(⊑ dcterms:subject);DCAT 3 放开了 range——主题不再自动是 skos:Concept
dcterms:publisher / license / issued…DCAT 没有 dcat:publisher——发布者、许可、日期全部复用 dcterms,取值推荐 foaf:Agent
dcat:landingPage⊑ foaf:page——落地页也是页面家族的一员
KEY POINT · 复用优先 DCAT 的设计纪律:外部词表已有的词不自造。dcterms 管元数据字段,foaf 管人和主页,prov 管溯源,skos 管主题,time / vCard / ODRL / SPDX 各取所需——这套复用策略本身就是建模课。

05实操坑清单 PART 4 · PITFALLS
  1. 没有 dcat:publisher:发布者写 dcterms:publisher,取值推荐 foaf:Agent——别找 dcat: 前缀。
  2. Dataset 与 Distribution 分开:「是什么」挂在 Dataset,「怎么下载」挂 Distribution——把下载 URL 写到 Dataset 上是常见错。
  3. accessURL ≠ downloadURL:端点 / 落地页用 accessURL,直链文件才用 downloadURL。
  4. theme 不再强制 skos:Concept:DCAT 3 放开 range——主题值用受控词表仍是好习惯,但不再是形式约束。
  5. DataService 也是目录条目:API 不是「数据集的附件」,而是与 Dataset 平级的 dcat:service。
  6. 版本选择:DCAT 3 supersede DCAT 2 但不使其 obsolete——存量数据不必迁移,新项目用 3。
  7. 画像先于自由发挥:欧盟场景对齐 DCAT-AP;自建画像时「加约束不加词」。
  8. 目录里可以再放目录:Catalog 是 Dataset 的子类,嵌套目录是合法形态——联邦检索的基础。
06一条目录记录 · Turtle PART 4 · A WORKED RECORD
<http://data.ex.com/catalog/kg> a dcat:Catalog ; dcterms:title "知识图谱数据目录" ; dcat:dataset ex:dataset-entities , ex:dataset-triples . ex:dataset-entities a dcat:Dataset ; dcterms:title "实体主数据" ; dcterms:publisher ex:org ; # 复用 dcterms,没有 dcat:publisher dcterms:issued "2026-10-15" ; dcterms:license <https://creativecommons.org/licenses/by/4.0/> ; dcat:distribution ex:dist-entities-csv . ex:dist-entities-csv a dcat:Distribution ; dcat:downloadURL <https://data.ex.com/entities.csv> ; dcat:mediaType "text/csv" .
读法 三层各就各位:目录(dataset)收录数据集(dataset)、数据集挂发布形态(distribution)、发布形态带下载地址与媒体类型——每个「是什么 / 怎么拿」都有明确落点。
