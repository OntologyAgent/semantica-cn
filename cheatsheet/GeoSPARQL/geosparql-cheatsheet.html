03核心词汇 · 要素与几何分离 PART 2 · CORE VOCABULARY
geo: 类一句话
geo:SpatialObject一切空间对象的根——Feature 与 Geometry 的父类
geo:Feature有空间表述的现实世界事物:一栋楼、一段管线、一个行政区
geo:Geometry几何形状本身;含 isEmpty / dimension 等几何属性
KEY POINT · 要素 ≠ 几何 同一个要素可挂多个几何:不同精度、不同坐标参照系(CRS)、不同时点。hasDefaultGeometry 指定「官方」几何。
sf: 几何类层级 · Simple Features(ISO 19125)
一维sf:Curve · sf:LineString · sf:LinearRing 二维sf:Surface · sf:Polygon 集合sf:MultiPoint · MultiCurve · MultiLineString · MultiSurface · MultiPolygon · GeometryCollection 零维sf:Point
几何挂接 要素经 geo:hasGeometry / hasDefaultGeometry 连到几何;几何经 geo:asWKT 给出 WKT 文本形态(数据类型 geo:wktLiteral)。

04查询函数 · 三套拓扑一族计算 PART 2 · SPARQL FUNCTIONS
函数族代表语义
Simple Featuresgeof:sfEquals · sfDisjoint · sfIntersects · sfTouches · sfCrosses · sfWithin · sfContains · sfOverlaps八种基本拓扑关系,最常用
Egenhofer / RCC8geof:ehEquals · geof:rcc8ec…更细粒度的定性拓扑词表,按领域选用
非拓扑计算geof:distance · geof:buffer · geof:convexHull · geof:intersection距离、缓冲区、凸包、几何运算
空间聚合geof:aggUnion 等GROUP BY 里聚合几何
KEY POINT 三套拓扑词表语义粒度不同:SF 八种够用就别上 RCC8——结论要能被下游读懂。
05一条地理查询 · SPARQL PART 2 · A WORKED QUERY
SELECT ?feature ?wkt WHERE { ?feature a geo:Feature ; geo:hasGeometry ?geom . ?geom geo:asWKT ?wkt . FILTER(geof:sfIntersects(?wkt, "POLYGON((116.3 39.8, 116.6 39.8, 116.6 40.1, 116.3 40.1, 116.3 39.8))"^^geo:wktLiteral)) }
读法 找出与给定多边形相交的所有要素:hasGeometry 找几何、asWKT 取形态、geof:sfIntersects 做拓扑判断——三步就是 GeoSPARQL 的全部骨架。
06实操坑清单 PART 4 · PITFALLS
  1. 几何类前缀是 sf::sf:Polygon 才对——geo: 是核心本体前缀,别写成 geo:Polygon。
  2. wktLiteral 带 CRS 前缀:默认 CRS84(经纬度);其他坐标参照系要在字面量开头声明 CRS URI。
  3. 要素与几何分开建模:属性挂 Feature,形状挂 Geometry——多精度、多时点几何可共存。
  4. 多几何要素认默认几何:hasDefaultGeometry 是「官方」形状,拓扑判断默认用它。
  5. 三套拓扑词表别混用:SF / Egenhofer / RCC8 粒度不同——下游能读懂哪套就用哪套。
  6. 大面数据先粗筛:先 bounding box 过滤再算精确拓扑,全表 sfIntersects 会拖垮查询。
  7. CRS 一致才可比较:两个几何坐标系不同,先变换再比——直接比较结果未定义。
  8. 时空成对:与 OWL-Time(PL.12)组合——geo: 管哪里,time: 管何时,观测类数据两维都要。
