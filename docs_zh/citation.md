## 引用格式

    ```bibtex

      title  = {Semantica: Graph-Native Infrastructure for Context and Accountable AI Systems},
      author = {Semantica},
      year   = {2026},
      url    = {https://github.com/semantica-agi/semantica},
      doi    = {10.5281/zenodo.XXXXXXX}
    }
    ```
  </Tab>
